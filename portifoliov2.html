Sistema de Lava-Rápido

Desenvolvimento de um sistema para gerenciamento de serviços de lava-rápido, com interface desktop desenvolvida em Delphi. O sistema permite o controle de atendimentos, registro de serviços e organização das informações operacionais.

Tecnologias: Delphi e Banco de Dados.

Sistema de Processamento de Vendas e Pagamentos

Desenvolvimento de uma aplicação em Python utilizando arquitetura baseada em comunicação entre processos. O projeto utiliza RabbitMQ para gerenciamento de filas, permitindo a integração entre as etapas de processamento de pagamentos e despacho de pedidos.

Foram utilizados JSON e CSV para manipulação de dados, além das bibliotecas Pika e UUID para comunicação com o RabbitMQ e identificação das operações.

Tecnologias: Python, RabbitMQ, Pika, JSON, CSV e UUID.
